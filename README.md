## 📖 서비스 소개

전국 최대 규모 IT 창업 연합 동아리 **'멋쟁이사자처럼 대학'** 소속, 이화여자대학교 인공지능대학 동아리 **'이화여자대학교 멋쟁이사자처럼'** 14기 운영진과
**해방이화 축제준비위원회**가 함께 제작한 **대동제 통합 안내 웹사이트**입니다.

부스·공연 운영자는 실시간으로 정보를 관리·홍보하고, 방문자는 실제 위치 기반의 지도와 검색으로 축제를 더 편하게 즐길 수 있도록 만들었습니다.

- 🗓 **이용 기간** : ~ 대동제 마지막 날 **2026년 5월 22일(금)** 까지
- 🔐 **로그인** : 카카오 소셜 로그인 (스크랩·관리자 기능)
- 🌐 **지원 환경** : 웹
- 📈 **이용 현황** : 총 방문자 **19,576명** · 페이지뷰 **56만 회** · 일 최대 방문자 **10,839명** (Google Analytics 기준)

### 👉 접속만 하면

- **부스 & 공연 지도** — 지도의 건물과 부스 번호를 클릭해 실제 위치 기반으로 정보를 탐색할 수 있어요. (줌/팬/회전 지원)
- **부스 & 공연 검색** — 부스/공연명·메뉴명·부스번호로 검색하고, 주관·카테고리·요일·위치로 필터링할 수 있어요.
- **부스 & 공연 상세 정보** — 운영일시·운영여부·위치·로드뷰·공지·메뉴·판매여부·세트리스트 등 실시간 정보를 조회할 수 있어요.
- **축제 시설·배리어프리 정보** — 취식공간·쓰레기통·물품배부 등 기타 시설과 배리어프리 정보를 확인할 수 있어요.

### 👉 1초 만에 카카오 로그인하면

- **부스 & 공연 스크랩** — 관심 있는 부스와 공연을 스크랩하고, 마이 페이지에서 모아볼 수 있어요.
- **부스 & 공연 관리** — 부스 및 공연 관리자가 실시간으로 정보를 수정할 수 있어요.

## 📂 디렉토리 구조

```
14th-Ewha-Festival-Front/
├─ public/                 # 정적 파일 (404.html, 파비콘 등)
├─ index.html
├─ vite.config.js          # Vite 설정 (base URL, '@' alias, HTTPS dev 서버)
└─ src/
   ├─ main.jsx             # 앱 진입점 (Provider 설정)
   ├─ App.jsx              # 라우팅 & 전역 오버레이(모달/토스트/바텀시트) 구성
   ├─ index.css            # 전역 스타일
   │
   ├─ pages/               # 라우트 단위 페이지
   │  ├─ home/             #   홈 · 카카오 리다이렉트 · 크레딧
   │  ├─ map/              #   지도
   │  ├─ my/               #   마이페이지 · 스크랩
   │  ├─ admin/            #   관리자(인증 · 내 부스/공연 · 수정)
   │  ├─ SearchPage.jsx    #   검색
   │  └─ NoticePage.jsx    #   공지
   │
   ├─ features/            # 도메인 단위 기능 (바텀시트)
   │  ├─ booth/            #   부스 리스트/상세 시트
   │  ├─ show/             #   공연 리스트/상세 시트
   │  ├─ FilterSheet.jsx   #   필터
   │  ├─ LoginSheet.jsx    #   로그인
   │  ├─ EtcSheet.jsx      #   기타 시설
   │  └─ BarrierFreeSheet.jsx  # 배리어프리
   │
   ├─ components/          # 재사용 UI 컴포넌트
   │  ├─ Card/             #   Booth·Show·Menu·Notice·Setlist·Review·Etc·Image 카드
   │  ├─ Input/            #   Input·TextArea·TextAreaSend
   │  └─ ...               #   Header·NavigationBar·Bottomsheet·Chip·Tab·Modal 등
   │
   ├─ apis/                # API 요청 모듈 (axios 인스턴스 · 도메인별 분리)
   │  ├─ accounts/  booths/  shows/  searches/
   │  └─ api.js            #   axios 기본 인스턴스
   │
   ├─ hooks/               # 커스텀 훅 (booth·show·map·my·search · 무한스크롤 등)
   ├─ store/               # Zustand 전역 상태 (auth·filter·toast·alert·modal 등)
   ├─ routes/              # 라우트 가드 (AdminProtectedRoute)
   ├─ layouts/             # 공통 레이아웃 (NavigationBarLayout)
   ├─ constants/           # 상수 (건물·카테고리·요일·지도 좌표 등)
   ├─ configs/             # 설정 (filterConfig)
   ├─ utils/               # 유틸 (date·error·label·mediaUrl·sns 헬퍼)
   ├─ data/                # 정적 데이터 (creditData·etcData)
   └─ assets/              # 이미지 · 아이콘 · 지도 리소스
```
